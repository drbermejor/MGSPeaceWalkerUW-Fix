# Peace Walker UltraWide Fix v0.1.0-rc.1

This is the first public candidate and is published as the current **Latest** release.

## Highlights

- Proper Hor+ ultrawide gameplay instead of a stretched 16:9 image.
- Optional centered 16:9 HUD, menus, subtitles and mission screens.
- Optional reversible Unity-launcher bypass.
- Guided Windows setup and Linux/Proton setup with custom Steam-library detection.
- Clean uninstall and SHA-256 checksums.

## Choose an asset

- **Windows:** `PeaceWalkerUltraWideFix-v0.1.0-rc.1-windows.zip`
- **Linux / Proton:** `PeaceWalkerUltraWideFix-v0.1.0-rc.1-linux.tar.gz`

## Important limitation

Some pure or long loading illustrations can switch to full-width and appear stretched near the end of loading. This does not affect the corrected 3D projection. If another 2D presentation issue appears, set `CenterHUD=0` and report the screen and resolution.

The primary visually verified mode is 3440×1440. Wider modes are welcome as candidate feedback.
